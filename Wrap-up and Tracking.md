# Workflow

**1.** Processor fills out blue sheet through microsoft form. 

**2.** Resource record is indexed on pipette, ticket is moved to "wrap up" section of blue sheet planner. Updates will display online immediately after indexing.

**3.** Update ASpace and New on the Web spreadsheet.  

**4.** Route to MARC


# ASpace

We update the ArchivesSpace accession record with basic processing information and stats. 

### Collection Management

Under "Collection Management" in the accession record in ASpace, update the "Processors" field with the processor's name, "processing total extent" with the number of linear feet, "extent type" as "linear feet", and the "processing status" field with the level of processing completed. 

![ASpace screenshot 1](https://github.com/llsmith305/images/blob/main/collection_management.PNG)

### User Defined Fields

Update the user defined fields with the number of items, AV/photographic/born digital item counts if applicable, new or addition, and stream/code.

Stream codes: I (intake processing), UD (user-driven), E (enhanced processing), LP (List2Proc), IP (Infrastructure preparation)

![ASpace screenshot 4](https://github.com/llsmith305/images/blob/main/user_defined.PNG)

Save accession.

### Create Event

At the top right of the accession record, click "add event" and select type "processed" for fully processed accessions or "processed [AV/photographs/mixed materials/etc.]" for partially processed accessions. Click "add event"

![ASpace screenshot 2](https://github.com/llsmith305/images/blob/main/ASpace_Capture2.PNG)

In the Date/Time specifier field, select UTC Timestamp. Enter a UTC Timestamp for the processing date. NOTE: the end date for our monthly processing stats is exclusive, so it helps to not use the last day of the month as a processing date.

![ASpace screenshot 3](https://github.com/llsmith305/images/blob/main/Processing_event.PNG)

Save event.

# Reporting

When all the accessions have been updated for the month, run a monthly processing stats report.

Find and select the Processing Statistic Report in ASpace. Enter your date range and format as csv. NOTE: the end date for our monthly processing stats is exclusive.

![ASpace sheetshot 5](https://github.com/llsmith305/images/blob/main/stats_report_1.PNG)

Download the report and save in departmental sharepoint: University of North Carolina at Chapel Hill\Wilson Technical Services - TS_Archival\monthly_stats
